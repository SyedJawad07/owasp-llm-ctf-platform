# 🏆 OWASP LLM Security CTF Platform

A Capture The Flag platform to learn LLM security vulnerabilities.

## Features
- 10 CTF Challenges (Easy to Expert)
- Points & Leaderboard
- User Authentication
- Beautiful Hacker UI

## Quick Start

### Backend
```bash
cd backend
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python3 app.py
```

### Frontend
```bash
cd frontend
npm install
npm start
```

Open: `http://localhost:3000`
